## 👨‍💻 Sobre mí

Soy desarrollador de software enfocado en la construcción de **aplicaciones web, APIs, sistemas empresariales, integraciones y automatización de procesos**.

Me interesa especialmente entender cómo funciona un proceso, identificar sus problemas y convertirlo en una solución tecnológica que sea **simple, mantenible, trazable y escalable**.

Mi experiencia abarca diferentes etapas del ciclo de desarrollo:

- 🗄️ Modelado y gestión de datos.
- 🔗 Integración entre sistemas.
- 🔄 Automatización de procesos.
- 🧪 Testing y aseguramiento de calidad.
- 🚀 CI/CD y procesos de despliegue.
- ☁️ Diseño de soluciones Cloud, híbridas y locales.
- 📊 Digitalización de procesos empresariales.
- 💡 Diseño y evolución de productos SaaS.
